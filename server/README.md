# ArtCraft Distribution & Mirror Server

Высокопроизводительный локальный сервер кэширования, раздачи релизов и зеркалирования пакетов для **ArtCraft Launcher** со встроенной веб-админ-панелью.

Написан на **Rust** (Axum 0.8, Tokio, Tower-HTTP, Reqwest).

---

## 🚀 Быстрый запуск

### 1. Запуск сервера:
```bash
cd server
cargo run
```
или запуск готового бинарника:
```bash
./server/target/debug/artcraft-server
```

Для сборки оптимизированной production-версии:
```bash
cd server
cargo build --release
./target/release/artcraft-server
```

### 2. Вход в админ-панель
Откройте в браузере:
👉 **[http://localhost:8080/admin](http://localhost:8080/admin)**

* **Пароль по умолчанию:** `admin123` *(переопределяется через `ADMIN_PASSWORD`)*

## 🌟 Умная логика кэширования и раздачи

Сервер реализует полную архитектуру безопасного зеркала для ArtCraft:

### 1. Пакеты приложений (Craft App Suite + SolidCraft + Launcher)
* **Если файл уже скачан на сервер** (лежит в `server/storage/`):
  Сервер мгновенно отдает его клиенту локально на максимальной скорости с поддержкой докачки (HTTP Range requests).
* **Если файла еще нет на сервере (On-Demand Caching)**:
  Когда клиент запрашивает файл через `/downloads/<filename>`:
  1. Сервер находит официальный адрес релиза на GitHub.
  2. Перенаправляет пользователя (HTTP 307) на прямой CDN GitHub, чтобы пользователь не ждал.
  3. **Одновременно сервер автоматически запускает фоновую загрузку** этого файла себе в `server/storage/` с проверкой хэша SHA-256.
  4. Все последующие скачивания этого файла будут отдаваться на 100% локально!

### 2. Проверка целостности (SHA-256)
* При каждой фоновой загрузке сервер сверяет контрольную сумму с официальным хэшем из манифеста релиза.
* При несовпадении хэша файл немедленно удаляется, гарантируя защиту от подмены.

### 3. Кэширующий прокси скриншотов (`/screenshots/<app>/<shot>.jpg`)
* Загружает скриншоты из официального репозитория `storytold/craft-launcher-assets/v1`.
* Проверяет сигнатуру байтов JPEG (`0xFF 0xD8 0xFF`) и лимит 2 МБ.
* Сохраняет в `server/storage/screenshots/<app>/<shot>.jpg` и кэширует в браузере.

### 4. Вкладка «Каталог приложений» в админ-панели (1-Click Suite Sync)
* Отображает актуальный статус всех 17 приложений пакета и самого лаунчера.
* Показывает, сколько пакетов уже закешировано локально.
* Позволяет в один клик:
  * Скачать конкретную платформу (macOS `.dmg`, Windows `.msi`, Linux `.AppImage`/`.deb`).
  * Скачать все пакеты для выбранного приложения.
  * **Запустить глобальную синхронизацию всех 17 приложений сразу.**
