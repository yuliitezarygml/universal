# Сервер «Искры»

В этой папке будет самостоятельный Rust-сервис с HTTP API на Axum и собственной PostgreSQL через SQLx. Он размещается на сервере «Искры» и обращается к OmniRoute за ответами моделей.

Первый этап включает миграции PostgreSQL, подтверждение email, создание аккаунта, выдачу и обновление токенов сессии и проверку личного лимита. Лимит привязывается к `account_id` и используется всеми устройствами пользователя. Код клиента находится в [`app/`](../app/README.md).

Контракт API, таблицы и критерии приёмки описаны в [ТЗ](../ISKRA-SPEC.md).
