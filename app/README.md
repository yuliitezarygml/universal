# Приложение «Искра»

В этой папке будет Flutter-клиент для iOS и Android. Приложение подключается по HTTPS к Rust API в [`server/`](../server/README.md).

После подтверждения email приложение сохраняет токены своей сессии в защищённом хранилище устройства. Остаток лимита и историю оно получает от сервера. Основные экраны и сценарии описаны в [ТЗ](../ISKRA-SPEC.md).
